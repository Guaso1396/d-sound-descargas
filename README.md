# D-Sound — Descargas

**[⬇️ Descargar D-Sound.apk](https://github.com/Guaso1396/d-sound-descargas/raw/main/D-Sound.apk)** · versión 1.3

Reproductor de música para Android **sin anuncios**, con consola DJ.

### Cómo instalar
1. Descarga **D-Sound.apk** con el enlace de arriba.
2. Ábrelo en el celular. Si Android lo pide, permite **"instalar apps desconocidas"**.
3. Si aparece un aviso de Play Protect, toca **"Instalar de todas formas"**.
4. Al abrir la app, acepta las **notificaciones** para que la música siga sonando con la pantalla apagada.

### Qué trae
- **Buscador global**: encuentra cualquier canción del celular por nombre o artista, sin importar la carpeta. Cada resultado muestra carpeta, ubicación, estado y versiones, y permite Reproducir, Agregar a la cola o **Ir a la carpeta**.
- Reproductor con círculo para adelantar, tiempo transcurrido y restante, y volumen propio.
- **Cola de reproducción**: sonando ahora, siguiente canción, canciones anteriores y próximas. Avanza sola.
- **Organizar**: selecciona canciones, mantenlas presionadas y muévelas; “Listo” guarda el orden.
- **Tipos de audio**: Normal, Sin voz y Solo voz. Las versiones se crean una vez por canción y se guardan aparte; el original no se modifica.
- **Biblioteca**: índice de la música del celular y carpetas que tú elijas.
- Consola DJ de dos platos.

Requiere Android 7.0 o superior.
